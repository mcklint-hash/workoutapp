# Min Träning 9.3

Filer:
- index.html
- style.css
- app.js

För att använda på GitHub Pages:
1. Ladda upp alla tre filer till samma mapp/repository.
2. Aktivera GitHub Pages för rätt branch.
3. Öppna webbplatsen och kontrollera att "Version 9.3" visas.

Viktiga ändringar från 9.2:
- Ny lagringsnyckel, gamla versioner skrivs inte över.
- Backup skapas vid migrering och import.
- Progressionsprocent kan väljas.
- Minsta viktökning är 2,5 kg.
- Statistik jämför samma repsantal.
- Muskelgruppsstatistik har lagts till.
- Egna upplägg kan skapas, redigeras och raderas.
- Pågående pass kan inte skrivas över utan varning.
